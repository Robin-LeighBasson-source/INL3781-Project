# Belgium Campus | Student Success & Risk Predictor

A modern, animated login page for the Belgium Campus ITversity Student Success and Risk Predictor platform. Built with **React** and **pure CSS3** (Flexbox/Grid only — no Tailwind, Bootstrap, or other CSS frameworks).

## Features

- Apple-inspired light blue accent (#5AC8FA)
- Smooth entrance and hover animations
- Mobile-responsive layout (works great with QR code demos)
- Pure CSS3: Flexbox, Grid, keyframe animations
- Component-based React structure

## Tech Stack

- React 18
- Vite 5
- Pure CSS3 (no frameworks)

## Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
